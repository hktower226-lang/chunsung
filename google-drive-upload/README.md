# Google Drive 사진 업로드 설정

1. 사진 보관에 사용할 Google 계정으로 https://script.google.com/ 접속 → **새 프로젝트**.
2. 프로젝트 이름: `집회신고 접수증 업로드`.
3. 기본 `Code.gs` 내용을 이 폴더의 **Code.gs 전체 내용**으로 교체.
4. 왼쪽 파일 옆 **＋ → HTML** → 이름을 정확히 **Upload**로 입력. 기본 내용을 **Upload.html 전체 내용**으로 교체.
5. 저장 후 **배포 → 새 배포 → 유형 선택(톱니바퀴) → 웹 앱**.
6. **실행 사용자: 나 / 액세스 권한: 본인만**을 선택. 불특정 사용자가 업로드하지 않도록 ‘모든 사용자’로 배포하지 마세요.
7. **배포 → 액세스 승인**에서 해당 Google 계정으로 Drive 권한을 승인. 직접 만든 프로젝트임을 확인하고 진행. 조직 정책상 허용되지 않으면 관리자에게 문의.
8. 표시되는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사. 배포 ID나 편집 화면 주소가 아닌 `/exec` 주소가 필요합니다.
9. 웹 앱 URL을 직접 열어 Google 로그인 후 사진 한 장 업로드. 지정 Drive 폴더에서 실제 저장을 확인합니다. 계정에 그 폴더의 파일 생성 권한이 있어야 합니다.
10. 저장소 `data.json` 최상위 `uploadUrl`의 빈 문자열을 웹 앱 URL로 교체하고 커밋. Pages 배포 후 대시보드에 **접수증 사진 업로드** 버튼이 나타납니다. 버튼은 Google 업로드 화면을 새 창으로 엽니다.

대상 폴더 ID는 Code.gs에 설정되어 있습니다: `1_VhjNfTPKWy-v_WsY-fZ6jT7VAaqN4Cg`.
사진 파일명은 `본부_건설사_저장일시_고유번호.jpg` 형식입니다. JPG/PNG/WEBP, 최대 10MB, 한 장씩 지원합니다. 파일 공유 권한은 코드에서 변경하지 않습니다. Drive 용량과 Apps Script 실행 한도가 적용됩니다.

최초 배포 후 코드 수정 시 **배포 → 배포 관리 → 수정 → 버전: 새 버전 → 배포**를 선택하세요. 기존 `/exec` 주소를 유지할 수 있습니다.

## 범위와 검증

사진 업로드는 대시보드 JSON 입력이나 사진 내용 인식을 수행하지 않습니다. 이 채팅의 과거 사진을 자동으로 가져오지도 않습니다. 사용자가 기기에서 사진 파일을 선택해야 합니다.

Google 로그인은 본인만 허용합니다. 다른 담당자에게 공유할 경우 별도의 접근 설계가 필요합니다. 이 코드는 자체적으로 로그인이나 사용자 검사를 구현하지 않으므로 **배포 접근 권한을 반드시 본인만으로 유지**하세요.

로컬에서 업로드 코드의 파일 형식·용량 검사, 파일명, 폴더 선택, 성공/실패 처리를 모의 검증했습니다. 실제 Google 권한 승인·배포·Drive 저장 검증은 위 설정 후 사용자 계정에서 완료해야 합니다. 웹 앱 URL이나 사진을 업로드했더라도 파일 공유 권한은 자동으로 공개되지 않습니다.
