# 수도권 본부 본사집회신고 공유 대시보드

`index.html`이 `data.json`을 읽는 정적 웹사이트입니다. 첨부 엑셀의 9개 열과 4개 본부를 반영했습니다. 엑셀의 실제 신고 내역은 비어 있으므로 초기 목록도 비어 있습니다. 기존 Streamlit 앱과 엑셀은 보존했습니다.

## 내용 수정

GitHub에서 **data.json → 연필(Edit) → 수정 → Commit changes**로 저장합니다. JSON은 큰따옴표를 쓰고 마지막 항목 뒤에는 쉼표를 넣지 않습니다. `reports` 배열에 다음 형태의 객체를 추가하세요. 아래 값은 형식 설명용 예시이며 실제 신고가 아닙니다.

```json
{
  "no": 1,
  "headquarters": "경기본부",
  "receiptNumber": "접수번호 입력",
  "company": "건설사명 입력",
  "location": "개최장소 및 행진진로 입력",
  "period": "집회 시작일 ~ 종료일 입력",
  "receivingAgency": "접수 경찰서 이름 입력",
  "reportedAt": "신고일자 입력",
  "reporter": "신고인 입력",
  "officerContact": "담당정보관 이름 / 연락처 입력"
}
```

`headquarters`는 최상위 `headquarters` 목록 중 하나여야 합니다. 접수번호는 앞자리 0을 보존하도록 문자열로 입력하세요. 날짜와 기간은 입력한 문자열 그대로 표시합니다. `updatedAt`은 자료 기준일(예: `2026-10-29`)이며 수정 시 직접 갱신하세요. `title`, `description`, 본부 목록도 JSON에서 바꿀 수 있습니다.

상단 본부 카드를 누르면 해당 본부 신고만 표시되고 검색어는 초기화됩니다. 전체 신고 카드를 누르면 전체 목록으로 돌아옵니다. 검색 초기화는 선택한 본부를 유지합니다. 담당정보관·연락처는 `officerContact`에 입력하며, 미입력 시 —로 표시됩니다. 개최장소 아래의 ‘건설사명 + 장소 복사’ 버튼 하나로 건설사명과 개최장소를 줄바꿈하여 함께 복사합니다. 접수기관은 `receivingAgency`에 경찰서 이름을 입력합니다. 검색, 본부별 건수, CSV 내려받기(담당정보관·연락처 포함), 인쇄를 지원합니다. 웹 화면에서 직접 편집하거나 GitHub에 저장하는 기능은 없습니다. GitHub의 JSON 파일을 수정하면 배포가 실행되고 웹페이지에 반영됩니다.

## GitHub Pages 배포

저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택합니다. `main`에 HTML 또는 JSON 변경을 올리면 `.github/workflows/pages.yml`이 자동 배포합니다. 최초 설정 후 Actions에서 워크플로를 수동 실행할 수도 있습니다. 실제 사이트 주소는 배포 성공 후 Pages 설정 또는 Actions 결과에서 확인하세요. Pages 활성화 및 사용 가능 여부는 저장소 권한·요금제에 따라 달라집니다.

배포 파일에는 `index.html`, `data.json`만 포함됩니다. Pages 게시 시 신고인·장소 등 JSON에 입력한 정보도 사이트 방문자가 열람할 수 있으므로 공유 범위에 맞는 자료만 입력하세요.

## 모바일 화면과 종료일 안내

모바일은 건설사명·집회기간만 보이는 접이식 목록입니다. 항목을 누르면 상세정보와 통합 복사 버튼이 나타납니다. PC 및 인쇄는 표 형식을 유지합니다.

신고마다 `endDate`에 종료일을 `YYYY-MM-DD` 형식으로 입력하세요. 예: `"endDate": "2026-11-19"`. 기존 자료에 종료일이 없으면 `period`의 두 번째 ISO 날짜를 사용합니다. 날짜가 올바르지 않으면 ‘종료일 확인 필요’로 표시합니다.

페이지를 열거나 새로고침하면 한국 시간(Asia/Seoul)의 오늘 날짜로 계산합니다. 종료일까지 0~7일이면 주황색으로 ‘재신고 필요’를, 기간이 지났으면 붉은색으로 ‘기간 만료’를 표시합니다. 종료일 당일은 ‘오늘 종료’이며, 다음 날부터 만료입니다. 안내는 재신고를 자동 접수하는 기능이 아닙니다. 브라우저 기기의 날짜·시간이 정확해야 합니다.

## Drive 접수증 사진 업로드

[설정 안내](google-drive-upload/README.md)를 따라 Apps Script를 실행 사용자 ‘나’, 액세스 ‘모든 사용자’로 배포하세요. `data.json`의 `uploadUrl`에 배포된 웹 앱 주소를 넣으면 업로드 버튼이 표시됩니다. 사진은 지정한 Google Drive 폴더에 보관되며 신고 JSON 자동 등록은 별도입니다.
